## How I work

```text
question -> baseline -> controlled experiment -> evaluation -> reproducible artifact
```

- Separate hypotheses, measured evidence, and decisions.
- Prefer small, falsifiable experiments over broad claims.
- Keep datasets, splits, metrics, checkpoints, and environment details traceable.
- Build the full path from research code to a usable pipeline.
